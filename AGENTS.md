# AGENTS.md

Python package boilerplate (IDU). Library source: `my_package/`; tests: `tests/`; Sphinx docs: `docs/`; example notebook: `examples/my_example.ipynb`. Package name, deps and tool config live in `pyproject.toml`.

## Environment

- Use Python 3.11 (`py -3.11 -m venv .venv`); CI uses 3.10. Avoid 3.15: the latest PyYAML (6.0.3) has no cp315 wheel, so pip tries a source build that needs MSVC, and the pinned tools crash there (`pylint==2.17.5` on removed `ast.Str`, `black==22.3` on `asyncio.get_event_loop`).
- Install test + tooling deps with `python -m pip install -e ".[dev,tests]"`. `make install-dev` installs only `[dev]`, which has **no pytest**; the test extra is named `tests`, not `test`.
- Version is generated by `setuptools_scm` from git tags/history; there is no `version` in `pyproject.toml`. `my_package.egg-info/`, `.venv/`, `.pytest_cache/` are gitignored.

## Commands

- Tests: `python -m pytest tests`; single test: `python -m pytest tests/test_1.py::test_my_function`
- Lint: `make lint` or `python -m pylint my_package`
- Format: `make format` runs `isort` then `black` and edits files in place
- Docs: `sphinx-build docs/source docs/build` (requires `.[docs]`; CI additionally installs pandoc for nbsphinx)
- Hooks: `pre-commit install` (`.pre-commit-config.yaml`: trailing-whitespace, end-of-file-fixer, black 22.10.0)

## Makefile / CI gotchas (verified)

- The test target is `tests` (plural) and a `tests/` directory exists, so `make tests` reports "up to date" and runs nothing. Use `make -B tests` or call pytest directly.
- `make venv` and `make build` call `python3`, which on Windows resolves to the Microsoft Store stub and fails. Use `py -3.11 -m venv` and `python -m build`.
- `.github/workflows/tests.yml` calls `make install-test` (extra `.[test]`, which does not exist) and `make test` (no such target), so CI as committed does not run the suite. Trust the Makefile and `pyproject.toml` over the workflow.
- pylint expects LF (`expected-line-ending-format = "LF"`), but a Windows checkout gives CRLF, producing `C0328` on every file (no `.gitattributes` exists). `make lint` also reports pre-existing issues in the shipped template code, so it exits non-zero out of the box.

## Conventions

- Docstrings follow numpydoc; line length is 120 (black/isort/pylint).
- `my_package/__init__.py` reads `importlib.metadata.version("my_package")`. When renaming the distribution, update the folder, `pyproject.toml` `name`, and this hardcoded string together.
- Release flow: pushing a `v*` tag triggers `pypi.yml` (release from `main`; `.dev`/`a`/`b`/`rc` pre-release from `develop`); docs deploy to the `documentation` branch on push to `main`.
