# Минимальные сохранённые данные Павловска

Точные копии результатов практики №2: `blocks.geojson`, `accessibility_matrix_drive.csv`, `provision_schools.csv`, `study_info.json`, `boundary.geojson`. Контрольные суммы каждого файла приведены в `manifest.json`. Архив города (~405 МБ) и дорожный граф не требуются для запуска приложения после сохранения матрицы.

Каталог `pavlovsk_study_data/` в корне проекта, если он существует, остаётся первичным источником и не изменяется приложением. Если его нет после передачи репозитория, приложение использует эту компактную копию. Записанные сценарии доступны и на копии только при совпадении контрольных сумм с исходным набором; это не фиктивные данные.
